## Introduction

This repository serves as a centralized location for academic presentations, research papers, and project documentation. The content is organized by subject area and includes materials from various academic disciplines including computer vision, deep learning, optical systems, and Internet of Things.

## Repository Structure

The repository is organized into the following main categories:

- **Paper Presentation**: Academic paper presentations and related materials
- **Paper Review**: Critical reviews and analyses of research papers
- **Project Paper**: Comprehensive project reports and documentation
- **Project Presentation**: Project presentation materials and slides
- **Proposal**: Research proposals and project proposals

Each category contains subdirectories organized by subject area for easy navigation and reference.

## File Descriptions

### Paper Presentation
- **Super-resolution Microscopy/**: Contains presentations and research papers on super-resolution microscopy techniques
  - `Paper_Presentation_1.pdf` & `Paper_Presentation_2.pdf`: Academic presentations on super-resolution microscopy topics
  - `Rapid, artifact-reduced, image reconstruction for super-resolution structured illumination microscopy.pdf`: Research paper on artifact reduction in structured illumination microscopy
  - `Superresolution by image scanning microscopy using pixel reassignment.pdf`: Research paper on image scanning microscopy techniques

### Paper Review
- **Computer Vision/**: Critical reviews of computer vision research papers
  - `Paper Presentation - Feed-forward 3D Reconstruction .pdf`: Review presentation on feed-forward 3D reconstruction methods
  - `Paper Presentation - Scene Coordinate Reconstruction.pdf`: Review presentation on scene coordinate reconstruction techniques
- **Introduction to Internet of Things/**: IoT-related paper reviews
  - `Introduction to Internet of Things Homework #4.pdf`: Homework assignment reviewing IoT papers

### Project Paper
- **Fourier Transform & Fourier Optics/**: Term report on Fourier analysis and optical systems
  - `B10901151_term_report.pdf`: Comprehensive term report on Fourier transform applications in optics
- **Introduction to Internet of Things/**: IoT project documentation
  - `Report.pdf`: Project report on Internet of Things implementation
- **Optical System Design/**: Optical engineering project
  - `B10901151.pdf`: Project report on optical system design principles

### Project Presentation
- **Computer Vision/**: Computer vision project presentations
  - `Microsoft 3D Reconstruction Group 13 待定.pdf`: Group presentation on Microsoft's 3D reconstruction techniques
- **Deep Learning for Computer Vision/**: Deep learning project materials
  - `final_presentation.png`: Final presentation image for deep learning computer vision project
  - `poster.pdf`: Academic poster presentation for deep learning research
- **Introduction to Automotive Electronics/**: Automotive electronics project reports
  - `Group_H_2-8D_report.pdf` & `Group_H_report.pdf`: Group project reports on automotive electronics systems
- **Introduction to Internet of Things/**: IoT project presentation
  - `看見個人環境健康風險.pdf`: Presentation on personal environmental health risk assessment using IoT

### Proposal
- **Super-resolution Microscopy/**: Research proposal materials
  - `Final_presentation.pdf`: Final presentation for super-resolution microscopy research proposal
